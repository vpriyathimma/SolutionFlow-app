# SolutionFlow App

SolutionFlow is a clean and efficient Expo-based Android application designed to simplify technical problem-solving by enabling users to instantly search Stack Overflow questions directly from their mobile device.

Built for developers, students, and tech enthusiasts, SolutionFlow provides a streamlined mobile interface to search programming-related queries, retrieve top Stack Overflow discussions, and quickly access relevant community knowledge without opening multiple browser tabs.

By integrating the Stack Exchange API, the app delivers fast, relevant, and user-friendly technical search results optimized for mobile productivity.

---

## Features

- Real-time Stack Overflow question search  
- Fetches top 10 relevant questions instantly  
- Displays total vote count for each question  
- Shows concise question descriptions  
- Highlights original question author  
- Minimalist and distraction-free mobile UI  
- Fast Android performance through Expo  
- Mobile-first developer productivity tool

## How It Works

1. Users enter a technical keyword or topic  
2. App sends the search request to Stack Overflow via Stack Exchange API  
3. Top 10 relevant questions are retrieved  
4. Results are displayed in easy-to-read cards  
5. Users can quickly review votes, summaries, and authors for efficient problem-solving

## Installation & Setup

### Clone the Repository
```bash
git clone https://github.com/vpriyathimma/SolutionFlow-app.git
cd SolutionFlow-app
```

### Development Requirements
- Node.js  
- Expo CLI  
- Android Studio Emulator or Expo Go App  
- Internet connection for API requests  

### Install Dependencies
```bash
npm install
```

### Run the Application
```bash
npx expo start
```

### Launch on Android
```bash
Scan QR code using Expo Go
or
Run on Android Emulator
```
